TRASFOMATA DI BURROWS-WHEELER  Filippo Marcialli 5Bt-i

BWT_executor.py: script in Python che, data una stringa in input, calcoli la sua trasformata di Burrows-Wheeler.
client.py e server.py: script "client.py" e "server.py" utilizzano dei socket TCP per lo scambio di informazioni. Il client invia una stringa al server; il server elabora la trasformata e la restituisce al client.
