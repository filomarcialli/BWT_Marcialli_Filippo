##TRASFOMATA DI BURROWS-WHEELER  Filippo Marcialli 5Bt-i

#PAGINE
###BWT_executor.py
Script in Python che, data una stringa in input, calcoli la sua trasformata di Burrows-Wheeler.
###client.py e server.py
Script "client.py" e "server.py" utilizzano dei socket TCP per lo scambio di informazioni. Il client invia una stringa al server; il server elabora la trasformata e la restituisce al client.
